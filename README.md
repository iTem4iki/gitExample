## Описание проекта

Предметная область — приём, регистрация, обработка и закрытие заявок пользователей в службу технической поддержки организации. Система хранит тему и описание проблемы, приоритет и статус заявки, историю переписки по заявке, а также оценку качества решения, которую оставляет клиент.

**Цели системы:**

- единый централизованный учёт всех заявок в техподдержку;
- сокращение времени реакции на обращения и решения проблем;
- прозрачность обработки заявки для клиента и контроль загрузки для оператора;
- сбор статистики для оценки эффективности службы поддержки;
- сохранение истории обращений и решений (база знаний).

## Пользователи и роли

| Роль | Возможности |
|---|---|
| **Клиент** | регистрация, создание заявки, просмотр статуса своих заявок, добавление комментариев, оценка решения после закрытия |
| **Оператор** | просмотр всех заявок, взятие заявки в работу, изменение статуса, закрытие заявки, добавление новых операторов |

## Основные функции

1. Регистрация и вход в систему с разграничением ролей (клиент / оператор).
2. Создание заявки с указанием темы, описания и приоритета.
3. Автоматическое присвоение заявке уникального номера и статуса `Новая`.
4. Просмотр списка и статуса заявок.
5. Взятие заявки в работу и изменение статуса (`В работе` → `Решена` → `Закрыта`).
6. Комментарии к заявке со стороны клиента и оператора.
7. Оценка клиентом качества решения.

## Архитектура

Классическая трёхуровневая архитектура:

- **Presentation Layer** — интерфейс пользователя (в данной версии — консоль);
- **Business Logic Layer** — обработка заявок, проверки, смена статусов;
- **Data Layer** — хранение данных (пользователи, заявки, комментарии).
