# Support Ticket Tracker

Учебный проект: система учёта заявок в техническую поддержку.

## Описание проекта

Предметная область — приём, регистрация, обработка и закрытие заявок пользователей
в службу технической поддержки. Система хранит тему и описание проблемы, приоритет
и статус заявки, историю переписки, а также оценку качества решения от клиента.

## Пользователи и роли

| Роль | Возможности |
|---|---|
| **Клиент** | регистрация, создание заявки, просмотр статуса своих заявок, комментарии, оценка решения |
| **Оператор** | просмотр всех заявок, взятие в работу, изменение статуса, закрытие заявки |

## Основные функции

1. Регистрация и вход с разграничением ролей.
2. Создание заявки (тема, описание, приоритет).
3. Автоматический статус `Новая` при создании.
4. Изменение статуса (`В работе` → `Решена` → `Закрыта`).
5. Комментарии и оценка решения.
